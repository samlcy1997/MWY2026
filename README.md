# MWY2026 Shanghai Interactive Trip Book

A mobile-first interactive trip book for a 3-day Shanghai itinerary around 未來有你 2026.

## Current RC1 scope

- Day 1 / Day 2 / Day 3 timeline
- Timeline ↔ interactive map linkage
- MapLibre + OpenFreeMap, no API key
- Per-stop full-page editorial details
- Restaurant pages: storefront recognition first, food visuals second, decision guidance third
- Shanghai Tower 118F multi-direction view explorer
- MWY event control centre with VERIFIED / CHECK / CONFLICT / TBA states
- Copyable place names / addresses / next-hop endpoints for use with Amap

## Deliberately dynamic / pending

- MWY merch Part.2
- MWY camera / bag / security / re-entry rules
- Late-October Xujiahui IP events
- Zhangyuan / The Louis current pop-ups
- Day-of ferry service and volatile restaurant hours

No booking numbers, payment details, personal account information, guest details, or other private trip records are included.
